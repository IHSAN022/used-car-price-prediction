# Used Car Price Prediction

Prediksi harga mobil bekas (Toyota) dengan machine learning.

- Used_car.ipynb : pipeline lengkap (loading, cleaning, EDA, modeling, deployment, monitoring)
- deployment/ : REST API Flask (jalankan: cd deployment, pip install -r requirements.txt, python app.py)
- dataset : "Dataset ini diambil dari Kaggle - 1000 Used Car Price Data oleh Nilesh Tiwari."
